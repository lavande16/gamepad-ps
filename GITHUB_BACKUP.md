# GamePad PS private backup

This repository contains the buildable GamePad PS V0.4.1 / 8 source and the
associated defaults and baseline metadata. The APK is published as the matching
private GitHub Release asset.

- Application ID: `com.gamepad.pspad`
- Version: `0.4.1 / 8`
- Build entry: `bash tools/build_runtime.sh`
- Baseline metadata: `baseline/`
- Build caches, generated APKs, local properties, debug keys, and large toolchain
  caches are intentionally excluded from the source repository.
